# 个人待办清单

个人待办清单是一款简洁清爽的任务管理工具，帮助你记录需要完成的事项，并按照优先级和时间安排日常计划。

## 主要功能

- **任务清单**：集中查看和添加所有待办任务。
- **我的一天**：查看安排在今天完成的任务。
- **重要任务**：快速查看已标记为重要的事项。
- **计划内**：查看安排在未来日期的任务。
- **任务管理**：支持编辑任务内容、设置日期和时间、标记完成以及删除任务。
- **任务分类**：可通过星标将任务加入重要任务，也可以为任务安排日期。
- **批量操作**：支持选择多条任务并统一删除。
- **状态提醒**：已完成的任务会以删除线显示，各栏目会同步显示未完成任务数量。

## 使用体验

界面采用简约的红色视觉风格，布局清晰，操作直观。任务信息会持续保留，方便你随时回到清单继续安排和完成事项。
