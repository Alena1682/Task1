# 个人待办清单

一个简约、干净的北大红色个人待办清单单页应用。界面只使用北大红色系，不包含校徽、校名或地点元素。

## 运行

在项目目录执行：

```bash
python -m http.server 4173
```

打开 <http://localhost:4173> 即可使用。

## 功能

- 左侧导航：任务清单、我的一天、重要任务、计划内
- 任务清单页支持不限条数新增任务
- 每条任务支持完成勾选、编辑、删除
- 编辑、垃圾桶删除和星标按钮始终显示在任务最右侧
- 每条任务最右侧的星标按钮可直接加入或移出“重要任务”
- 编辑时可修改内容、安排日期和时间（小时 0–23、分钟 00–59 的下拉菜单），并标记重要任务
- 日期输入为空时以“年 / 月 / 日”作为整齐的默认提示，并通过日历按钮选择日期
- 编辑窗口中的“标记为重要任务”控件与上方内容区域保持左侧对齐
- 日期为今天的任务自动出现在“我的一天”
- 其他日期的任务自动出现在“计划内”
- 任务清单中的原任务始终保留，分类页面只是筛选视图
- 支持全选、多选并批量删除，删除会同步影响其他分类页面
- 左侧各栏目数字显示该分类下未完成的任务数，任务完成后会自动减一
- 使用浏览器 `localStorage` 自动保存，刷新后数据不会丢失
- 右上角日期会根据本机日期动态更新，跨过午夜后页面保持打开也会自动刷新
- 点击添加区域左侧“＋”或空内容时的“添加”按钮，会自动聚焦任务输入框
